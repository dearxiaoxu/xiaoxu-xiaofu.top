# 🚀 云服务器部署指南（中国大陆服务器版）

> 一条重要背景：你的服务器在中国大陆，`.top` 域名绑定前**必须先完成 ICP 备案**（约 1–2 周）。
> 所以分两步走：
> **第一步（今天就能做）**：部署后用 `http://服务器IP:3000` 访问，先让网站跑起来；
> **第二步（备案通过后）**：绑定域名 + 上 HTTPS。

---

## 第一步：上传项目到服务器

任选一种方式，把**整个项目目录**传上去（包含 `server.js`、`admin/`、`js/`、`css/`、`data/`、`deploy/` 等）：

**方式 A：scp（macOS 终端直接传）**
```bash
scp -r ~/Documents/xiaoxu-xiaofu.top root@你的服务器IP:/root/
```

**方式 B：GitHub 中转**
本地把项目推到 GitHub 私有仓库，服务器上：
```bash
git clone https://github.com/你的用户名/仓库名.git
```

**方式 C：宝塔/FinalShell 等工具**直接拖拽上传。

---

## 第二步：运行一键部署脚本

登录服务器，进入项目目录，执行：

```bash
cd /root/xiaoxu-xiaofu.top        # 或你上传的目录
sudo bash deploy/deploy.sh         # 想先看会执行什么：bash deploy/deploy.sh --dry-run
```

脚本会自动完成：
1. 检查/安装 Node.js 22 LTS（内置 SQLite；Debian/Ubuntu 用 apt，CentOS/Rocky 用 yum/dnf）
2. 同步代码到 `/opt/xiaoxu-xiaofu`（**服务器上的 data/ 数据永不覆盖、永不删除**）
3. 提示你设置管理员初始密码
4. 注册 systemd 服务（开机自启、崩溃自动重启）
5. 尽力开放本机防火墙端口
6. 健康检查并打印访问地址

---

## 第三步：云控制台放行端口

登录你的云服务商控制台 → 找到该服务器 → **安全组/防火墙规则** → 添加入方向规则：

| 协议 | 端口 | 来源 |
|------|------|------|
| TCP | 3000 | 0.0.0.0/0（或你的常用 IP） |

> 80/443 端口等备案通过后再放行（未备案时大陆服务器对外提供 80/443 Web 服务可能被限制）。

---

## 第四步：验证

- 前台：`http://服务器IP:3000/`
- 后台：`http://服务器IP:3000/admin/`（登录后**立即修改密码**）
- 健康检查：`curl http://127.0.0.1:3000/healthz`，返回 `status: ok` 才算服务正常

常用运维命令：
```bash
systemctl status xiaoxu-xiaofu     # 看状态
journalctl -u xiaoxu-xiaofu -f     # 实时日志
systemctl restart xiaoxu-xiaofu    # 重启
```

---

## 第五步：备案通过后绑域名 + HTTPS

1. **域名解析**：在域名注册商处添加两条 A 记录，都指向服务器 IP：
   - `www` → IP
   - `@`（裸域）→ IP
2. **安装 Nginx**：
   ```bash
   apt install -y nginx certbot python3-certbot-nginx   # Ubuntu/Debian
   ```
3. **配置反代**：把 `deploy/xiaoxu-xiaofu.conf` 复制到服务器：
   ```bash
   cp deploy/xiaoxu-xiaofu.conf /etc/nginx/conf.d/xiaoxu-xiaofu.conf
   nginx -t && systemctl reload nginx
   ```
4. **签发 HTTPS 证书**（certbot 会自动改写配置）：
   ```bash
   certbot --nginx -d xiaoxu-xiaofu.top -d www.xiaoxu-xiaofu.top
   ```
5. 访问 `https://www.xiaoxu-xiaofu.top`，完成 🎉

---

## 日常更新与备份

- **更新代码**：本地改完 → 重新上传 → 重跑 `sudo bash deploy/deploy.sh`（数据不动，几秒生效）
- **备份数据**：先执行 `systemctl stop xiaoxu-xiaofu`，再运行 `cd /opt/xiaoxu-xiaofu && npm run backup`；备份目录默认在 `/opt/xiaofu-backups/`，恢复前保持服务停止
- **轻量备份**：也可通过后台「数据与安全」页导出内容 JSON，但它不包含上传图片和运行日志
- **安全建议**：修改默认密码、SSH 改用密钥登录并关闭密码登录、安全组只放行必要端口

## 常见问题

| 现象 | 处理 |
|------|------|
| 浏览器打不开 IP:3000 | ① 安全组没放行 3000；② `systemctl status xiaoxu-xiaofu` 看服务是否在跑 |
| 后台页面空白 | 服务在跑但 JS 没加载：强制刷新（Cmd+Shift+R）；看浏览器控制台报错 |
| 上传图片失败 | Nginx 阶段检查 `client_max_body_size`；直连阶段检查后台日志 |
| 忘记管理员密码 | `rm /opt/xiaoxu-xiaofu/data/admin.json && systemctl restart xiaoxu-xiaofu`（恢复默认 admin123，登录后改回） |
